默认生产检索层只接收实验谱。标准品、植物组织生物谱和公共原始数据分层保存；in silico 谱仅进入 shadow 层。公共原始 LC-MS/MS 必须经过方法/极性核验、共识谱构建和可追溯注释后，才可成为参考谱。

重要：只有包含真实碎片强度的测量结果才作为实验谱；仅列 fragment_mz、没有 intensity 的文献表会标为“文献靶标线索”，不能获得实验谱高置信鉴定。
质量门控：系统核验 formula–adduct–precursor、SMILES–formula 和 InChIKey 一致性；不一致行隔离且不写入数据库。
支持格式：CSV/Excel、MGF、MSP、质心 mzML，以及“谱图图片 + V15 JSON 清单 + 经人工复核的峰表”。mzXML 必须先规范化为质心 mzML；Thermo .raw、Agilent .d 等厂商原始文件先走系统的原始数据转换流程。
对照品重复谱：同一结构、分子式、加合物、极性、仪器、活化方式、采集方法、批号以及固定 CE 完全一致时，系统自动用同批技术重复生成一张共识谱；原文件哈希和成员扫描号写入审计信息，技术重复只计一份独立证据。
图片边界：PNG/JPEG/TIFF 不会仅凭像素进入实验谱检索。图片必须关联至少 3 个经复核的 m/z–intensity 数值和横轴提取方法；入库时保留图片哈希，但图片数字化强度只进入文献靶标/复核记录。
缺 InChIKey/SMILES：可按“名称+分子式”保存为低证据线索；系统不会再按名称自动借用结构，避免异构体串库。
